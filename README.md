# MK Holidays — Modern Travel Website Homepage

A clean, modern, and fully responsive travel website homepage built from scratch using plain **HTML5** and **CSS3** (no frameworks). Designed as an original portfolio project for front-end development.

## ✨ Key Features
- **Custom Branding**: Designed under the original brand **MK Holidays ** with modern typography (`Plus Jakarta Sans`).
- **Interactive Search & Filter**: Includes location inputs, category selection, price ranges, and rating filters.
- **Card Layouts**: Built using **CSS Grid** to display destinations, popular hotels, and top-rated restaurants with hover zoom animations.
- **Fully Responsive**: Adapts seamlessly to mobile, tablet, and desktop screens using custom CSS Media Queries.

## 🛠️ Built With
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, CSS Grid, Custom Properties / Variables)
- **Google Fonts**
